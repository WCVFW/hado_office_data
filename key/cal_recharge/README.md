# Calzone Recharge App

This project has been implemented with a React frontend and Node.js backend.

## Structure
- `client`: React + TypeScript (Vite)
- `server`: Node.js + Express

## Setup
1. **Database**: Ensure you have a MySQL database running and update `server/.env` with your credentials.
2. **Install Dependencies**:
   ```bash
   cd server
   npm install
   cd ../client
   npm install
   ```

## Running
- Server: `cd server && npm run dev`
- Client: `cd client && npm run dev`
